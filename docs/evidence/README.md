# Retained evidence

This directory stores machine-readable run artifacts, source/runtime identities and measured outcomes. Use the authored [qualification reports](../qualification/README.md) and [performance reports](../performance/README.md) to understand the scope, then follow their links to the exact artifact.

Existing artifacts are immutable historical records. Paths and source hashes inside them describe the captured source revision, which may precede the documentation reorganization. Do not rewrite those paths to make an old run look like it used today’s tree. Local `.qualification/` output paths may require the retained local fixture or the original run environment.

Current release conclusions belong in [release gates](../roadmap/release.md), not in the filename/date of the newest JSON file. Failed tests and unsupported load envelopes remain evidence too.
